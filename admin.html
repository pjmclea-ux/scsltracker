📖 Setup & Usage Guide

🔥 Step 1 — Firebase Setup

  1. Go to console.firebase.google.com → Add Project → name it scsl-tracker-2026
  2. Build → Realtime Database → Create Database → Start in test mode
  3. Rules tab: set to { "rules": { "scsl": { ".read": true, ".write": true } } }
  4. Project Overview → Web icon (</>) → Register app → copy config → paste into both HTML files replacing REPLACE_WITH_YOUR_...

🌐 Step 2 — GitHub Pages

  1. New GitHub repo → upload both files as index.html and admin.html
  2. Settings → Pages → Deploy from main branch → Save
  3. Public URL: yourusername.github.io/scsl-tracker

📂 Step 3 — Upload Bill Book

  1. Go to Bill Book tab → upload your .xlsx file
  2. Columns needed: Bill No. / Bill Author / Delegation / Purpose Statement
  3. Optional: add a Hotness column (1–5) — otherwise auto-scored from keywords
  4. Verify the column mapping → click Import Bills → bills are saved to Firebase

🗓 Step 4 — Set Session Dates

  1. Go to Schedule tab → set the calendar dates for Day 1/2/3
  2. Adjust floor time windows as needed → Save to Firebase

📊 Step 5 — Google Sheets Auto-Sync (Optional but Powerful)

  1. In your docket Google Sheet: File → Share → Publish to web → choose your sheet → Tab-separated values (.tsv) → Publish → copy URL
  2. Settings tab → paste TSV URL → Connect & Start Auto-Sync
  3. Auto-timing: When a bill changes from blank/pending → "in progress", the timer starts automatically. When it changes to passed/failed/tabled, the duration is recorded. No manual timing needed!
  4. Polls every 20 seconds. All detected changes logged in the Change Log.

🏛️ Using During Session

  • Manual mode: Hit 🔴 Floor when bill starts → ✅/❌/⏸ when done. Duration auto-calculates.
  • Sheets auto mode: Just update your Google Sheet. Changes sync in ~20s and timing is automatic.
  • Duration displayed as H:MM (e.g., 0:14 = 14 minutes, 1:05 = 1hr 5min)
  • Tabled = returns later (50% time remaining estimated). Tabled Indefinitely = excluded from projection.
