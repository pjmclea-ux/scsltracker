📖 Setup & Usage Guide

🔥 Step 1 — Create a New Firebase Project

  1. Go to console.firebase.google.com and click Add Project
  2. Name it something like scsl-tracker-2026 → Disable Google Analytics → Create Project
  3. Once created, click Build → Realtime Database → Create Database
  4. Choose any location → Start in test mode → Enable
  5. In Realtime Database → Rules tab, set rules to:
    { "rules": { "scsl": { ".read": true, ".write": true } } }
  6. Go back to Project Overview → Click the web icon (</>) → Register app → Get your config object
  7. Replace the REPLACE_WITH_YOUR_... placeholders in BOTH index.html and admin.html with your real Firebase config values

🌐 Step 2 — Deploy to GitHub Pages

  1. Go to github.com → New repository → name it scsl-tracker → Public → Create
  2. Upload both files. Rename: scsl_index.html → index.html and scsl_admin.html → admin.html
  3. Go to Settings → Pages → Source: Deploy from branch → main → / (root) → Save
  4. Your URLs: yourusername.github.io/scsl-tracker (public) and yourusername.github.io/scsl-tracker/admin.html (admin)

🤖 Step 3 — Set Up Groq AI (Free)

  1. Go to console.groq.com → Sign up (free, no credit card)
  2. Create an API key
  3. Come to Admin → Settings → Groq API Key → Paste → Save
  4. The key is stored in Firebase — it never appears in your GitHub code

📊 Step 4 — Connect Google Sheets (Optional but Recommended)

  1. Open your SCSL docket Google Sheet
  2. Make sure column headers are exactly: Bill No. / Bill Author / Delegation / Purpose Statement / Status / Vote Count / Executive action
  3. File → Share → Publish to web → choose your sheet tab → CSV format → Publish → Copy link
  4. Go to Admin → Settings → Google Sheets → paste URL → Connect
  5. Status values that sync: passed / failed / tabled / tabled indefinitely / In progress
  6. Re-sync anytime by clicking Re-sync Now

🏛️ Using During Session

  • Mark a bill "🔴 On Floor" when it comes up — floor timer starts automatically
  • Enter minutes manually in the Min field, or use the Start/End time columns for precise timing
  • Mark Passed / Failed / Tabled when done — projection updates instantly for everyone
  • Tabled = bill will return later (counts ~50% time remaining). Tabled Indefinitely = won't return (excluded from projection)
  • The public index.html updates in real-time for all viewers — share that URL with everyone in the room
  • The Statistical Projection at the top of the public page is the primary display — the AI panel is supplemental

🔐 Passwords & Security

  • Default admin password: tigers — change in Settings → Admin Password
  • Password is stored in your local browser — different devices each need to set it
  • Firebase rules are public read, but anyone who wants to write needs to know your Firebase project config — keep that private
  • Groq API key is stored encrypted in Firebase and never exposed in GitHub source code
